# RAG Poisoning Detection: multi-signal black-box detector


## Setup (Windows, once)
```bat
python -m venv .venv && .venv\Scripts\activate
REM GPU (NVIDIA): pick the CUDA build from pytorch.org, e.g.
pip install torch --index-url https://download.pytorch.org/whl/cu121
REM CPU only:  pip install torch
pip install -r requirements.txt
REM LLM (only for step 4 / demo): install Ollama from ollama.com, then
ollama pull llama3:8b
```
Use a different LLM with `set OLLAMA_MODEL=mistral:7b`.

```bat
run_v4.bat
```

Or step by step:

| Step | Script | Output |
|---|---|---|
| 1 | `01_prepare_data.py --dataset nq` | clean KB (gold + 20k distractors), poisons (`prag`, `prag_noq`, `inject`), targets |
| 2 | `02_retrieve_signals.py --dataset nq` | `data/nq/features.csv` (S1–S4 + baseline features), `results/nq_latency.json` |

## Design (fixed rules)
- LLM is a black box. Detection uses only retrieved text, metadata and retrieval scores; no extra LLM calls.
- S1 retrieval-score z-score within top-K · S2 regex + `protectai/deberta-v3-base-prompt-injection-v2`
  · S3 pairwise contradiction, `cross-encoder/nli-MiniLM2-L6-H768` · S4 source credibility.
- Scorers: weighted sum (weights + threshold grid-searched on training folds), Random Forest, XGBoost.
- Baselines: no defence, keyword (regex), embedding-anomaly (centroid outlier), GPT-2 perplexity filter,
  TrustRAG stage-1 filter (K-means + n-gram, ported from github.com/HuichiZhou/TrustRAG; no LLM step).
- Variants: xgb_nos4 (without simulated S4), xgb_lite (without S3/NLI).
- Adaptive attacks (01b, generated by the local LLM): prag_div (5 stylistically different poisons per question),
  inject_llm (LLM-written injection poisons). Plus an S4-spoofing test in 03.
- Evaluation: 5-fold CV grouped by question (no question in both train and test).

## Things that must be stated in the paper
- Attack texts: PoisonedRAG released texts (Zou et al., USENIX Security 2025), black-box variant
  (question prepended); `prag_noq` = same texts without the question prefix (adaptive attacker);
  `inject` poisons are templated by us (8 templates, `01_prepare_data.py`).
- S4 provenance is **simulated** (corpora have no source metadata): clean 60/30/10 % high/medium/low
  credibility, poisons 20/30/50 % (20 % spoof a trusted source). Report the `-S4` ablation alongside.
- KB is a sampled subset of the BEIR corpus (gold passages + 20k random passages), not the full corpus.
- Retriever: all-MiniLM-L6-v2 (PoisonedRAG used Contriever).

`RAGP_MOCK=1` runs everything with stand-in models for code testing only. Never report mock numbers.
